# ✂️ Trimly - Beauty Service Booking Platform
<p align="center">
  <b>A complete full-stack beauty service marketplace connecting users, service providers, and administrators in one seamless platform.</b>
</p>
---
## 🚀 Overview
**Trimly** is a modern beauty service booking platform designed to simplify the way customers discover, book, and manage beauty services.
The platform provides a complete ecosystem with three dedicated applications:
- 👤 **User Platform** - Customers can explore services, find providers, and book appointments.
- 💼 **Provider Platform** - Service professionals can manage profiles, services, availability, and bookings.
- 🛠️ **Admin Dashboard** - Administrators can manage users, providers, services, and overall platform operations.
Built with a focus on smooth user experience, scalability, and efficient appointment management.

# ✨ Features
## 👤 User Features
- User authentication and profile management
- Browse available beauty services
- Explore service providers
- View provider details
- Book appointments
- Manage bookings
- Responsive user-friendly interface
## 💼 Provider Features
- Provider authentication
- Create and manage service profiles
- Add and update offered services
- Manage appointment requests
- Track booking status
- Provider dashboard
## 🛠️ Admin Features
- Admin authentication
- Manage users and providers
- Manage platform services
- Monitor appointments
- Control overall application workflow
- Centralized dashboard management
